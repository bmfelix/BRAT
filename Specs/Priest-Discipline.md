12.1.5 made no Discipline class changes except tuning (Smite +40%, Void Blast +25%,
Entropic Rift damage up; Atonement transfer raised).

## Damage priority (Icy Veins 12.1.5)
1. Shadow Word: Pain if missing on your target
2. Mind Blast (procs Void Shield; Voidweaver: opens Entropic Rift)
3. Penance and Void Shield when available (both on cooldown: Void Shield is a large share of output)
4. Shadow Word: Death, Void Blast, Smite fill the gaps
   - Voidweaver: Void Blast replaces Smite while Entropic Rift is active; spam it in the rift.
   - Void Blast can beat Shadow Word: Death even in execute → Death is mostly a movement spell.
